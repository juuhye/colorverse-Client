현재 브랜치를 main 브랜치와 비교하여 변경된 코드만 리뷰한다.

절대 파일을 수정하지 말고 리뷰 결과만 출력한다.

## 프로젝트 스택

- Next.js App Router
- TypeScript
- React
- FSD Architecture
- Zustand

## 리뷰 기준

우선순위는 아래 순서를 따른다.

1. 실제 런타임 버그
2. 타입 안정성
3. 보안
4. 인증/인가
5. 성능
6. React Hook 사용 오류
7. Next.js App Router 규칙
8. 접근성
9. 유지보수성

다음은 지적하지 않는다.

- Prettier 스타일
- 세미콜론
- 따옴표
- 개인 취향
- 함수 이름 취향
- "더 예쁘게 작성 가능" 같은 의견

## 출력 형식

아래 형식을 그대로 따른다.

```
# Summary

전체 품질 요약

---

# Critical

...

---

# High

...

---

# Medium

...

---

# Low

...
```

각 문제마다 반드시 아래 항목을 포함한다.

- 파일
- 문제
- 왜 문제인지
- 수정 예시 코드

문제가 없다면 다음과 같이 출력한다.

"Approve 추천"
